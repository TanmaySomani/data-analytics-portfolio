# Data analytics portfolio

Five interactive Streamlit dashboards and accompanying reproducible analyses, built with published real-world datasets. The sales and e-commerce projects use the same historical UK retailer data for different questions.

| Dashboard | Dataset | Scope |
|---|---|---|
| Sales performance | [UCI Online Retail](https://doi.org/10.24432/C5BW33) | Invoice-line value by country, month and stock code |
| Customer churn | [UCI Iranian Churn](https://doi.org/10.24432/C5JW3Z) | Churn labels and customer attributes from a telecom sample |
| Marketing campaigns | [UCI Bank Marketing](https://doi.org/10.24432/C5K306) | Term-deposit subscription outcomes from phone campaigns |
| E-commerce customers | [UCI Online Retail](https://doi.org/10.24432/C5BW33) | Identified customers and 90-day repeat purchasing |
| Employee attrition | [U.S. BLS JOLTS](https://www.bls.gov/opub/ted/2026/quits-rate-3-5-percent-in-accommodation-and-food-services-august-2026.htm) | Industry-level, seasonally adjusted monthly quits rates |

## Run all five dashboards locally

From the repository root, with Python 3.10 or newer:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run streamlit_app.py --server.address 127.0.0.1
```

On Windows activate with `.venv\Scripts\activate` instead. Open the address printed by Streamlit and choose a dashboard in the sidebar. The first installation requires internet; the app uses the included data files at runtime. Press Ctrl+C to stop the server.

Each project also works independently: run `python -m streamlit run dashboard.py` from its project folder. The `PROJECT_EXPLANATION.md` files document the data, metrics, decisions, limitations and individual dashboard controls. Presentations are in each project's `presentation.pptx`. To rebuild the cleaned data and outputs from the included source, run `python project.py` in that project folder; presentations are snapshots and are not regenerated by this command.

## Streamlit Community Cloud

Deploy this repository with `streamlit_app.py` as the main file. The root `requirements.txt` contains the dependencies. Community Cloud initializes the application from the repository root. The app needs no secrets or database. Datasets and source attribution are included under each project’s `data/` directory. See the [deployment guide](https://docs.streamlit.io/deploy/streamlit-community-cloud/deploy-your-app/deploy).

## Interpretation and data attribution

- The sales and e-commerce measures exclude cancellation and nonpositive lines; they are not net revenue or profit. Unit costs are unavailable. Follow-up for repeat purchases is limited to the observed data.
- The bank campaign data does not include spend or incremental lift. The churn and marketing comparisons show associations, not causal effects.
- The attrition dashboard uses a small published industry-level extract, not individual employee records. August 2026 estimates were preliminary when published.
- The three UCI datasets are provided under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/); creator citations and source file details are in each project’s `data/SOURCE.md`. The JOLTS extract is attributed to the U.S. Bureau of Labor Statistics.
