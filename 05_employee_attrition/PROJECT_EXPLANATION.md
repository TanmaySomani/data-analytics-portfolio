# Employee Attrition Analysis: project explanation

## 1. Business question
How do U.S. voluntary separation rates vary by industry, and where should an employer benchmark retention?

## 2. Source and scope
U.S. Bureau of Labor Statistics, The Economics Daily, “Quits rate 3.5 percent in accommodation and food services, August 2026,” 13 October 2026.

Source documentation: https://www.bls.gov/opub/ted/2026/quits-rate-3-5-percent-in-accommodation-and-food-services-august-2026.htm

One published industry-level, seasonally adjusted quits-rate comparison for August 2025 and August 2026. The 2026 estimates were preliminary when published.

Included raw file: `raw.csv`. SHA-256: `e241de2b794bd11297ab76d46c90bf322049f669072c8e58c633681a03991fd1`.

The CSV is a manually transcribed extract of the source table, restricted to the published industry rows and the all-industry total. It is a snapshot of figures as published, not a live feed.

## 3. Data dictionary
- industry: published industry grouping or all-industry total.
- aug_2026_quits_rate_pct: seasonally adjusted monthly quits rate, preliminary at publication.
- aug_2025_quits_rate_pct: corresponding published rate one year earlier.
- change_pp: 2026 rate minus 2025 rate, in percentage points.

## 4. Cleaning and quality checks
19 transcribed table rows, including one all-industry total; source values are seasonally adjusted rates. All 19 rows have both published comparison values. The total is excluded from the industry ranking.

Review `data/clean.csv.gz` for the analytical records. Duplicate-looking records are not removed without a reliable event identifier. `unknown` categories are retained where present. Quality rules are explicit in `project.py`.

## 5. Metrics and definitions
- Monthly quits rate = number of quits during the month ÷ employment × 100, as defined by BLS.
- Quits are generally voluntary separations and exclude retirements and transfers to other locations.
- Year-over-year change is August 2026 rate minus August 2025 rate, in percentage points.
- These are monthly, seasonally adjusted survey estimates, not annual employee turnover rates.

## 6. Results
| Metric | Value |
|---|---:|
| Total quits rate | 1.9% |
| Highest industry | 3.5% |
| Lowest industry | 0.5% |
| Reference month | Aug 2026 |

### Findings
1. Accommodation and food services has the highest listed quits rate at 3.5%.
2. Federal government has the lowest listed rate at 0.5%.
3. Retail trade increased +0.6 percentage points from August 2025 to August 2026.

Detailed segment counts and values are in `outputs/`. Percentages in text and slides are rounded; CSVs retain greater precision.

## 7. Recommendation
Compare an organization’s own monthly voluntary quits with the closest industry benchmark and investigate differences using confidential aggregate employee feedback.

### Next steps
1. Align the organization’s quits definition, month and denominator with the BLS definition.
2. Compare against the closest industry over a longer series, accounting for sample uncertainty.
3. Use aggregated exit feedback and a voluntary intervention to test actionable hypotheses.

## 8. Limitations and interpretation
This is a small manually transcribed extract of a BLS table, not individual-level employee data. It cannot identify reasons for leaving, employee characteristics or causal factors. The latest month was preliminary at publication; estimates can be revised and survey uncertainty matters. Industry comparisons do not control for workforce composition.

These findings describe the supplied historical data; they should not be presented as results for another company or as causal effects.

## 9. Reproduce the analysis
1. Install Python 3.9+ and the dependency: `python3 -m pip install -r requirements.txt`.
2. From the project folder, run `python3 project.py`. The included source file is read locally; no network connection is needed.
3. Review `outputs/summary.json`, the segment CSVs and `data/clean.csv.gz`. Re-running overwrites generated outputs and this explanation but preserves the raw source file.
4. Open `presentation.pptx`. The deck is a snapshot of this analysis and is not automatically regenerated by `project.py`.

## 11. Run the interactive dashboard

From a terminal opened in this project folder, create and activate a virtual environment, then install the dependencies:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

On Windows, activate the environment with `.venv\Scripts\activate` instead. The initial installation requires internet access. Then start the dashboard:

```bash
python -m streamlit run dashboard.py --server.address 127.0.0.1
```

Open the local URL printed in the terminal (normally `http://localhost:8501`). Stop the server with Ctrl+C. To run another dashboard at the same time, use a different port, for example append `--server.port 8502`. The dashboard reads the included local files and does not need internet access after installation. If an analysis output is missing, run `python project.py` first.

Select one or more industries, then choose a comparison of both years or the percentage-point change. The national benchmark remains visible; the table and CSV contain only selected industries. August 2026 rates were preliminary when published and are not individual employee records.

Changes to filter selections affect the dashboard only. Run `python project.py` to rebuild the cleaned data and analysis outputs from the included source; the dashboard detects the updated files. The presentation remains a separate snapshot and is not rebuilt by the dashboard or analysis script.
